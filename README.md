## # Hi, I'm Luca Paganini 👋

MSc Finance student at the University of Bologna - ClamFim, with a strong interest in Finance.

I build projects at the intersection of financial theory and data — using Python to apply models I actually study and care about.

---

## 🔍 What I Work On

- **Risk modelling** — VaR, GARCH, backtesting frameworks
- **Portfolio optimization** — Markowitz, Risk Parity, Ledoit-Wolf shrinkage, CVaR
- **Machine learning in finance** — ensemble models, regime detection, SHAP explainability
- **Market dynamics** — volatility spillovers, lead-lag relationships, correlation analysis

---

## 📂 Projects

| Project | Description | Key Methods |
|---|---|---|
| [var-risk-analysis](https://github.com/luca-paganini/var-risk-analysis) | Comparative VaR analysis: S&P 500 vs Euro Stoxx 50 (2005–2024) | GARCH(1,1), GJR-GARCH, Kupiec & Christoffersen backtesting |
